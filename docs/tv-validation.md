# TV 实机验收（待执行）

本版只完成源码、构建与本地逻辑测试；没有连接或更新电视。以下项目需要使用者允许操作电视后执行。

## 遥控与导航

- 从首页 → 搜索 → 详情 → 播放，逐级按返回，确认没有回桌面；保存进度、停止声音、交还常亮状态。
- 播放选集 / 倍速 / 换源面板先关闭，再次返回才离开播放页；设置选项、添加源与导入面板同理。
- 首页在其他标签或筛选面板按返回先复位；首页连续按返回仍留在应用内；Home 键继续交给系统。
- 方向键可访问海报、播放、线路、每一集、播放器控制与设置行，确认焦点框可见，没有焦点陷阱；返回后焦点恢复是否合理。
- 控制条隐藏时左右键每次跳 10 秒，确认暂停 / 继续，上下唤出控制条；显示时方向键优先在控件间移动；音量和系统快捷键继续可用。
- 用灵犀指针点击、滚动，检查两栏详情、长简介、长剧集列表和播放面板；验证窄屏回退布局。

## 播放与媒体会话

- 在线 / 离线、续播、换集、换线、换源、播放器缓存节点再次进入、后台再回前台。
- 系统播控触发播放 / 暂停、seek、上 / 下一集；对照片名、集名、时长、进度、速度。
- 小艺是否实际向本应用下发标准播放命令另行记录，不以 AVSession 注册成功代替语音实测。

## 手机 / 电视应用接续（1.10.0-tv.2）

- 两端安装同版本、签名 / 应用身份满足条件，登录同一账号并开启系统接续。分别允许与拒绝多设备协同权限，核对系统入口是否出现及提示是否清楚。
- 播放页“分享 → 跨设备续播”，完成手机 → 电视和电视 → 手机；检查影片、集数、线路、进度、速度与播放 / 暂停状态。
- 目标冷启动、后台热启动、当前正在播放其他影片 / 直播时接收；不能重复压栈或出现两路音频。
- 连续 A → B → A，多次接续和重复请求；源端迁移成功后退出并停止声音 / 画中画，失败时源端仍能继续观看。
- 对端旧版本、源端未就绪 / 离线文件、无片源配置、临时 URL 失效、设备断网 / 拒绝迁移，不得打开错误影片或卡在无响应界面。
- 当前集不依赖目标已配置片源即可尝试播放；完整选集需配置对应源，不能误认为订阅也已经同步。

## 画质

- 普通开关关闭、开启、设备不支持、没有回调时的 UI 状态。
- 720p / 1080p 24–30 fps、60 fps、4K、倍速、动态分辨率片源；记录 superResolutionChanged 是否开启，确认不支持时可继续或重试普通播放。
- HDR 片源等比显示、颜色与亮度是否正常；不把普通 SDR 超分标志当作 HDR 状态。
- 电视系统运动流畅度关闭 / 低 / 中 / 高，同一运动片段对照；记录是否影响本应用及是否产生插帧伪影。
- 对照播放器超分与电视系统超分，避免未经验证的重复处理；无法确认鸿鹄硬件链路时如实标注。
