# 电视点播控件（tv.30）

顶部左侧显示片名、片源 / 集名和播放时间。声音补偿、鸿鹄画质、倍速、选集、下一集、换源、广告诊断和返回集中在右上角，空间不足时换行；原片分辨率 / 编码和超分状态在操作下方。电视移除铺满屏，保持原始比例。

底部只保留进度滑块。中间没有独立播放按钮，整个视频区域可点击：正在播时暂停，暂停时继续；暂停后保留控件，继续播放后延时隐藏。顶栏与进度条是直接放在视频点击层之上的两个独立浮层，以默认命中处理子控件并阻止其范围内点击落到后方；中部没有整屏控件容器。选集、倍速等面板仍处理自身操作。

电视的方向输入继续使用既有 PanGesture；不再把电视视频点击送入手机的长按加速分支。手机保留原控制条及原有点击行为。

tv.29 原生检查确认左侧 / 右侧视频点击可暂停 / 继续，但发现顶栏和进度容器误用 Block：该模式阻止子节点命中，按钮无法点选。tv.30 去掉整屏控件容器及 Block，按上述独立浮层重做命中。

待实机复查：各中部位置、控件显隐两态下的暂停 / 继续；点顶部按钮和拖进度不误触暂停；有多集时所有操作位于屏内；暂停中打开 / 关闭面板；返回到原资源页。
