# 电视点播控件（tv.31）

顶部左侧显示片名、片源 / 集名和播放时间。声音补偿、鸿鹄画质、倍速、选集、下一集、换源、广告诊断和返回集中在右上角，空间不足时换行；原片分辨率 / 编码和超分状态在操作下方。电视移除铺满屏，保持原始比例。

底部只保留进度滑块。中间没有独立播放按钮，整个视频区域可点击：正在播时暂停，暂停时继续；暂停后保留控件，继续播放后延时隐藏。布局容器自身使用 None，不参与命中；顶栏和进度区使用默认命中，接收各自子控件并阻止范围内点击落到后方。中部空白不参与命中，由底层视频点击层处理。选集、倍速等面板仍处理自身操作。

电视的方向输入继续使用既有 PanGesture；不再把电视视频点击送入手机的长按加速分支。手机保留原控制条及原有点击行为。

tv.29 原生检查确认左侧 / 右侧视频点击可暂停 / 继续，但发现顶栏和进度容器误用 Block：该模式阻止子节点命中，按钮无法点选。tv.30 用不参与命中的整屏 Column 排列默认命中的顶栏与进度区；中间 Blank 同样使用 None，保持自然顶部 / 底部定位。

tv.30 实机确认顶部倍速按钮打开面板，原生保持 PLAYER_PAUSED，返回关闭面板；左中部暂停、右中部继续，5.2 秒后控件隐藏，中部点击再次暂停并显示控件。底部进度区点击没有穿透暂停，但原处理只接受拖动 End，忽略了 Click，因此 tv.31 同时处理 Click / End，实际 seek 效果继续复验。有多集时的完整操作矩阵和遥控焦点遍历仍待完成。
