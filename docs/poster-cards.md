# 电视影视卡片

1.10.0-tv.14 采用原生 ArkUI，保留竖版海报比例与圆角。片名直接叠在海报上，用多层文字阴影提高可读性，不再铺整块模糊底。

- 左上角：豆瓣评分；未知时显示暂无评分。
- 名字旁：按累计短评数显示火焰，评分与热度独立。
- 名字下：最多三个类型。
底栏在海报下方独立延伸，不覆盖海报；海报、底栏和悬停外框使用一致的 24 vp 圆角边界，外框不参与内容尺寸。片名和类型使用大范围深色投影，无热度图标时标题贴左。

- 底栏左侧：纯文字上映 / 首播日期，无日历图标；只有年份时显示年份。
- 底栏中间：国家 / 地区旗帜；合拍最多两面，其余用 +N。未知映射显示地球图标，悬停或聚焦可查看地区全名。
- 底栏右侧：电影显示分钟数，缺失时显示电影；剧集显示总集数，缺失时显示剧集。总集数不表示当前片源已更新完毕。

底栏采用首个制作地区的低饱和暗色：中国为暗红 `#49363B`，韩国为灰蓝 `#334751`，日本为灰粉 `#4C3C46`，其他已支持地区各有暗色；未知地区默认灰色 `#363940`。合拍旗帜仍展示完整地区，不依据当前筛选条件猜测制作地。

## 热度口径

只使用豆瓣详情的 `comment_count`（短评总数），不使用 `rating.count`（评分人数）或 `review_count`（长评数）替代。

| 档位 | 累计短评数 | 外观 |
| --- | --- | --- |
| 未评级 | 未获取 / 无有效字段 | 无火焰，保留未知状态 |
| 冷门 | 0–999 | 无火焰 |
| 关注 | 1,000–9,999 | 14 vp 琥珀色空心焰 |
| 热门 | 10,000–49,999 | 16 vp 橙色实心焰 |
| 大热 | 50,000–199,999 | 18 vp 红橙双层焰，轻光晕 |
| 现象级 | 200,000 及以上 | 20 vp 金红焰、浅色焰芯和小火星 |

没有火焰时不渲染图标占位，片名从左侧内边距开始；有火焰时显示在片名左侧。仅可见且悬停 / 聚焦的大热及现象级卡片轻微呼吸；默认静态。火焰悬停和无障碍描述提供实际短评计数。阈值是产品分档，不是豆瓣官方实时热度榜，也不表示影片质量。

## 数据与缓存

推荐列表只提供基础字段。可见卡片使用豆瓣网页使用的详情 JSON：`https://m.douban.com/rexxar/api/v2/{movie|tv}/{subjectId}`，按条目真实 `is_tv` / `type` 区分电影与剧集。类型提示不匹配且返回普通 400/404 时，只换另一种类型尝试一次；HTTP 400、错误码 1309 / subject_ip_rate_limit 单独识别为限流，不能换类型重复请求。

详情字段：`rating.value`、`countries`、`genres`、`durations`、`episodes_count`、`pubdate`、`year`、`comment_count`。日期优先选择豆瓣列出的中国大陆公映 / 首播日期，否则采用首个有效日期，再回退到条目年份；它不保证是全球最早发行日，重映日期可能晚于条目年份。

这是网页详情接口，不附带开放 API 的稳定性承诺。卡片资料、评分和短评数永久持久化保存；内存只保留最近 200 条，内存淘汰不会删除磁盘条目。沿用已有稳定资料缓存，旧记录没有评分 / 短评缓存时继续正常补齐。

评分与短评数以最近一次成功获取完整详情的时间为准。未超过 2 天时直接复用；超过 2 天仍先显示旧数据，再后台获取，成功后才替换并更新时间，失败保留旧数据和原时间。可见卡片每 30 秒检查一次过期，离开可见区或销毁后停止检查；检查不等于每次都发送网络请求。重新进入或重启也先从缓存展示，不出现因过期清空评分和热度的闪烁。

同 ID 的在途请求合并，最多并发两个，完整详情请求起始至少间隔 750 ms。详情和推荐请求仍关闭 NetworkKit HTTP 缓存，由应用显式控制 2 天刷新周期。失败至少退避 1 分钟；400 限流、401/403/429 或验证页使完整详情队列暂缓 5 分钟，冷却时间跨重启保存，不执行验证页脚本。

完整详情失败时优先保留现有缓存；没有缓存时使用公开 `https://movie.douban.com/j/subject_abstract?subject_id=…` 摘要接口补齐地区、类型、年份、片长和总集数。摘要只有年份时不会伪造月日，不采用摘要的评分，不生成短评热度。已有热度和评分可继续显示；从未获取的字段保持未知。

只查询标记为豆瓣来源的推荐条目，不将 Bangumi 或点播源自身的编号当作豆瓣 ID。

## 素材与验证

韩国旗预先展开引用并烘焙变换为独立路径，避免电视端 SVG 解码器对嵌套引用的差异。

旗帜使用 [flag-icons](https://github.com/lipis/flag-icons) 7.6.0 的 37 个本地 SVG，采用 MIT 许可，原文见 [FLAG-ICONS-LICENSE.txt](FLAG-ICONS-LICENSE.txt)。火焰与地球图形是本项目 SVG，不依赖系统 Emoji 字体或在线旗帜图片。

测试使用 2026-10-25 实际响应的必要字段快照，并覆盖数据缺失、计数口径、分档边界、电影 / 剧集分支、缓存及并发和退避。原生组件的完整实机验收另记于 [TV 验证记录](tv-validation.md)。
