# 影片详情与片源探测

电视推荐和主动搜索的影片卡片统一进入独立的 Discovery 介绍页。搜索页负责查找影片，选中后展示影片介绍与各源资源；手机保持原流程。

## 布局与导航

点击后卡片从原位置放大移至左侧，保留海报与独立底栏；导演、主演显示在卡片下方。中间从顶部开始展示片名、原名、评分、类型和 17 fp 简介，行高 29；不重复底栏的地区、日期和片长 / 集数。右侧按匹配影片分组，每个实际片源一个按钮。

页面没有顶部标题栏或屏幕返回按钮。遥控器返回逆向收起详情；从播放器返回则保留详情和结果。

卡片以初始尺寸渲染，使用缩放和平移，进入曲线为 580 ms cubic-bezier(0.2, 0, 0.2, 1)。固定模糊背景渐显，资料面板独立淡入。动画、资料补齐和搜索分别启动，互不等待。声明期望帧率不代表已经测得稳定帧率。

## 搜索缓存

- 应用私有文件永久保存搜索结果，不因过期删除。身份包含关键词、已启用源及接口配置和内容过滤设置；改变配置不复用旧身份。
- 先展示缓存。超过 24 小时自动刷新；未过期也能手动刷新。刷新期间旧按钮仍可选，失败保留原结果与时间。
- 同一搜索合并在途请求；离开页面后响应可更新缓存，不会覆盖另一影片。返回子页面后可重新接上仍在执行的刷新。
- 缓存保存片源 ID、名字、封面和画质文字等搜索字段，不持久化容易失效的播放 URL。单文件有大小限制，写入后原子替换。

## 点击即播放

点击任一片源直接进入播放器，不再经过第二个详情页。优先使用探测时已获取的短期详情；没有详情时只在所点击按钮显示“正在打开”，其他按钮仍可选，后一次点击覆盖前一次意图。请求失败留在当前页并提示换源。

自动优先选择直接 HLS 线路；同一片源与影片已有记录时恢复有效线路、集数和位置，没有记录时从第一集或影片开头播放。线路编号随历史记录持久化。播放详情在内存复用 5 分钟，探测与点击共用请求，避免重复请求触发源站限流。

## 探测与尺寸口径

仅对可见按钮排队，入口动画结束后启动，最多并发两个。离开页面或开始播放会取消无订阅者的待执行任务，运行中的任务在有界步骤完成后停止继续取流。

按钮的毫秒数是播放清单请求或文件 HEAD 的 HTTP 耗时，包含服务器响应与网络开销，不是 ICMP ping、持续下载速度或整段影片的缓冲保证。

1. HLS 主清单有 `RESOLUTION` 时，选最大声明规格并显示 `≤宽×高`。这是变体声明的上限提示，播放器实际采用的轨道规格以播放页为准。[HLS RFC 8216](https://www.rfc-editor.org/rfc/rfc8216#section-4.3.4.2) 将此属性定义为可选的变体显示分辨率。
2. 清单没有尺寸时，最多读取 512 KiB 的未加密媒体前缀，交给 API 11 起提供的 AVMetadataExtractor 读取真实宽高。提取超时 1.5 秒后释放；不创建播放器，不产生音频。加密片段不采样。
3. 仍没有尺寸时，保留源站画质文字并明确标注“源标注”；不会把 HD 猜成 1080p。没有任何信息则显示“尺寸未提供”。

清单限制 128 KiB，最多跟随三层，单次清单请求最多 4 秒，清单阶段有总时间限制。成功探测缓存复用 24 小时，失败 5 分钟后可重试；刷新按钮可强制更新当前可见结果。记录永久保存，不存播放地址；刷新失败时保留旧尺寸并标“上次”。

探测不依赖 API 26 专属提取超时方法，可用于 API 24 电视。部分格式的前缀缺少索引、源站限制 Range 或需要鉴权时，尺寸可能无法提前获取；测速成功也不保证播放一定成功。

## 验证范围

本地测试覆盖持久化与时效、旧结果可选、全失败保留缓存、迟到响应隔离、共享请求、并发上限、取消订阅、清单解析及尺寸来源、提取器释放、直接播放选择与历史记录。时间过期使用模拟时钟，未让电视实际等待一天。

原生布局、缓存恢复、刷新中选择与媒体输出的实际结果见 [TV 实机验收](tv-validation.md)。全部格式、全部片源、完整键盘焦点和动画性能矩阵尚未完成。

## 电视主动搜索（tv.26）

主动搜索的电视结果列表改用与首页相同的圆角海报卡片，六张一行，通过单一 List / LazyForEach 按行创建，可视区外只缓存一行。顶部为紧凑搜索框，结果行显示聚合片源数量。手机继续使用现有纵向搜索结果和详情路径。

点击电视搜索结果进入同一 Discovery 介绍页，使用卡片实际屏幕位置做放大过渡。搜索结果携带的资源编号立即显示在右侧，不重新等待一次聚合搜索；已完成的完整搜索按原关键词持久化，刷新也沿用原关键词并按选中影片筛选；超过一天的入口数据才自动后台更新，未过期可手动刷新，更新期间仍可选已有资源。新搜索结果优先于旧的影片名缓存，返回播放器后可复用更新缓存。资源选择沿用直接进入播放器、分辨率 / HTTP 耗时探测、永久缓存和续播逻辑。

右侧按已选影片的规范化片名和年份筛选刷新结果。年份未知时以源 / VOD 编号确认身份，不把同名重拍版直接拼在一起；被禁用或被当前成人源过滤策略排除的源不展示。找不到同一版本的更新结果时保留原先已搜索到的资源。

资料先用搜索响应中的类型、地区、年份、简介、导演和演员；后台通过已有 DetailCache 补齐首个资源的详情，与资源探测共享请求。只使用源站明确提供且格式有效的 `vod_douban_id` 去补充豆瓣资料；CMS 的 VOD 编号不会被猜成豆瓣编号，缺失评分 / 热度也不会伪造。路由只传展示资料和源身份，不复制完整分集列表或有时效的播放 URL。

144 项本地测试通过，新增覆盖 CMS 资料与明确豆瓣 ID、脚本 / HTML 清理、影片 / 剧集提示、资料合并、同名不同年份隔离，以及搜索结果立即可选、不重复请求、比旧缓存更新、过期与刷新失败保留等。release 构建与离线签名验签完成；本轮未连接或操作电视，原生输入、焦点、动画和实际搜索到播放的完整路径仍待验证。
